# معرفة عنوان IP العام لخادم VPS بعد الاتصال عبر SSH

<img src="/images/articles/check-vps-ip.webp" alt="طرفية SSH على خادم VPS تعرض الأمر curl myip.dog وعنوان IP توضيحياً" width="1536" height="1024" className="w-full h-auto rounded-xl border border-border" />

*رسم توضيحي أصلي. عنوان IP الظاهر في الصورة مجرد مثال.*

بعد الدخول إلى خادم VPS عبر [SSH](/ar/ssh-command/)، قد تحتاج إلى معرفة العنوان الذي يستخدمه للاتصال بالإنترنت. نفّذ `curl myip.dog` في طرفية الخادم للحصول على عنوان مصدر الطلب. هذه طريقة سريعة للتحقق من الشبكة أو جمع معلومات لطلب الدعم، دون فتح لوحة تحكم الاستضافة.

## نفّذ الأمر على الخادم

تأكد أولاً من أنك تعمل داخل جلسة SSH الخاصة بالـVPS. إذا نفّذت الأمر على جهازك الشخصي قبل الاتصال بالخادم، فستحصل على عنوان اتصالك المحلي بالإنترنت.

```bash
curl myip.dog
```

عند نجاح الطلب، يظهر عنوان بصيغة نصية بسيطة:

```text
203.0.113.42
```

هذا عنوان توضيحي فقط. عنوان IP العام لخادمك هو القيمة التي تظهر فعلياً في الطرفية. يرسل curl الطلب، ثم يعيد MyIP.dog عنوان المصدر الذي يراه. لا تحتاج إلى تثبيت برنامج نصي إضافي للاستعلام.

لإجراء الاستعلام عبر اتصال HTTPS مشفّر، يمكنك استخدام:

```bash
curl https://myip.dog
```

## كيف تفهم النتيجة؟

تعرض النتيجة عنوان IP العام المستخدم في هذا الطلب الصادر تحديداً. إذا كان الخادم يمر عبر بوابة NAT أو وكيل اتصال أو VPN، فقد يظهر عنوان تلك الخدمة الوسيطة. لذلك قد يختلف عن عنوان واجهة الشبكة أو العنوان الذي استخدمته للدخول عبر SSH. كذلك لا يعرض الأمر جميع العناوين المخصصة للـVPS.

يمكن أن تكون النتيجة IPv4 أو IPv6 بحسب الاتصال. يشرح [دليل curl الرسمي](https://curl.se/docs/manpage.html) الخيارات المتاحة. قبل توجيه اسم نطاق إلى الخادم، تأكد من مزود الاستضافة من عنوان الاتصالات الواردة، وراجع إعدادات NAT والجدار الناري. نجاح الاستعلام عن IP لا يثبت أن الموقع أو منفذ SSH متاحان من خارج الشبكة.

## إذا ظهر خطأ

تعني رسالة `curl: command not found` أنك تحتاج إلى تثبيت curl باستخدام مدير الحزم في توزيعة Linux. إذا فشل حل اسم الموقع، فتحقق من DNS. وإذا انتهت مهلة الاتصال، فراجع اتصال الخادم بالإنترنت وإعدادات الوكيل. احتفظ بنص الخطأ لتسهيل تحديد السبب.

## أدوات أخرى على MyIP.dog

تعرض [الصفحة الرئيسية لـMyIP.dog](https://myip.dog/) عنوان IP العام لاتصال المتصفح. فتحها من جهازك لا يستعلم تلقائياً عن عنوان الـVPS البعيد.

تضم [صفحة الأدوات](https://myip.dog/tools) استعلام DNS، واختبار IPv6، وفحص منافذ TCP، وPing، وTraceroute، وIP WHOIS، وحاسبة الشبكات الفرعية. اختر الأداة حسب السؤال الذي تريد الإجابة عنه، مثل سجلات النطاق أو إمكانية الاتصال بخدمة TCP. يبدأ Ping وTraceroute من نقطة قياس بعيدة، لذا انتبه إلى موقعها عند قراءة النتائج.

دوّن عنوان IP العام للـVPS ووقت الاستعلام. سيساعدك ذلك على مقارنة النتائج بعد تعديل الإعدادات أو شرح المشكلة للدعم الفني.
