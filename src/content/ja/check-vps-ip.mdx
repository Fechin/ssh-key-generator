# SSH 接続後に VPS の IP アドレスを確認する方法

<img src="/images/articles/check-vps-ip.webp" alt="VPS に SSH 接続し、curl myip.dog で外向き通信の IP アドレスを確認するイメージ" width="1536" height="1024" className="w-full h-auto rounded-xl border border-border" />

*説明用のイラストです。表示されている IP アドレスは実際の取得結果ではありません。*

[SSH](/ja/ssh-command/) で VPS にログインしたあと、外部から見える IP アドレスを手早く確認したいことがあります。ネットワーク設定には複数のアドレスが並ぶため、どれが通信に使われているか迷うこともあるでしょう。そんなときは、サーバー上で `curl myip.dog` を実行すると、そのリクエストの送信元 IP を確認できます。

## VPS の端末でコマンドを実行する

まず、操作している端末が VPS の SSH セッションであることを確認してください。手元のパソコンで実行すると、パソコン側のネットワークの IP アドレスが返ってきます。

```bash
curl myip.dog
```

成功すると、次のように IP アドレスが文字列で表示されます。

```text
203.0.113.42
```

これは説明用のアドレスです。実際には、お使いの VPS からの接続で観測された値が返されます。curl がリクエストを送信し、MyIP.dog が送信元のアドレスを返す仕組みなので、専用のスクリプトを用意する必要はありません。

HTTPS で通信したい場合は、次のように指定できます。

```bash
curl https://myip.dog
```

## 確認できるのは外向き通信のアドレス

この方法で得られるのは、今回の通信で使われたグローバル IP アドレスです。NAT、プロキシ、VPN を経由している場合、ネットワークインターフェースのアドレスや SSH 接続先のアドレスと一致しないことがあります。VPS に割り当てられたすべての IP を一覧表示するコマンドではありません。

また、接続経路によって IPv4 または IPv6 が返されます。詳しいオプションは [curl の公式マニュアル](https://curl.se/docs/manpage.html)をご覧ください。ドメインの接続先を設定するときは、VPS 事業者が案内する公開アドレス、NAT の設定、ファイアウォールも確認しましょう。送信元 IP が分かっても、外部から Web サイトや SSH に接続できるとは限りません。

## エラーになったときの確認点

`curl: command not found` と表示されたら、利用中の Linux のパッケージ管理ツールで curl をインストールします。名前解決に失敗した場合は DNS、タイムアウトした場合は外向き通信やプロキシの設定を確認してください。エラーの内容を控えておくと原因を調べやすくなります。

## MyIP.dog のオンラインツールも活用する

[MyIP.dog のトップページ](https://myip.dog/)では、ブラウザーの接続元 IP を確認できます。手元のパソコンで開いたページから、VPS の IP が自動的に分かるわけではありません。

[ツール一覧](https://myip.dog/tools)には、DNS 検索、IPv6 接続テスト、TCP ポートチェック、Ping、Traceroute、IP WHOIS、サブネット計算があります。DNS 設定を確認したいのか、公開ポートを調べたいのかに合わせて選ぶと便利です。オンラインの Ping と Traceroute は遠隔の測定拠点から実行されるため、拠点の場所も合わせて確認してください。

VPS の IP アドレスを調べたら、取得時刻も記録しておきましょう。設定変更前後の比較や、サポートへの問い合わせに役立ちます。
