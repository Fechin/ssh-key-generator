# SSH 접속 후 VPS 공인 IP 확인하는 방법

<img src="/images/articles/check-vps-ip.webp" alt="VPS의 SSH 터미널에서 curl myip.dog로 외부 통신에 사용되는 IP를 확인하는 예시" width="1536" height="1024" className="w-full h-auto rounded-xl border border-border" />

*직접 제작한 설명용 이미지입니다. 화면의 IP는 예시 주소입니다.*

[SSH](/ko/ssh-command/)로 VPS에 접속한 뒤 공인 IP를 확인해야 할 때가 있습니다. 웹사이트를 설정하거나 외부 통신 문제를 점검할 때 특히 유용합니다. 네트워크 인터페이스에 표시된 여러 주소 중 무엇을 봐야 할지 헷갈린다면, `curl myip.dog`로 이번 요청에 사용된 주소부터 확인해 보세요.

## VPS에 접속한 터미널에서 실행하기

명령어는 반드시 VPS의 SSH 세션에서 실행해야 합니다. 내 컴퓨터의 터미널에서 바로 실행하면 서버가 아니라 내 컴퓨터가 사용하는 네트워크의 공인 IP가 나옵니다.

```bash
curl myip.dog
```

요청이 성공하면 다음처럼 IP 주소가 텍스트로 표시됩니다.

```text
203.0.113.42
```

위 주소는 설명을 위한 예시입니다. 실제 VPS 공인 IP는 터미널에 반환된 값을 확인하세요. curl이 요청을 보내면 MyIP.dog가 관측한 출발지 IP를 돌려주는 방식이라 별도의 조회 스크립트를 설치할 필요가 없습니다.

암호화된 HTTPS 연결로 조회하려면 다음 명령어를 사용할 수 있습니다.

```bash
curl https://myip.dog
```

## 조회 결과를 해석할 때 주의할 점

이 명령어는 이번 외부 요청에 사용된 공인 IP를 알려줍니다. NAT 게이트웨이, 프록시 또는 VPN을 거치면 해당 서비스의 IP가 표시될 수 있습니다. 따라서 네트워크 인터페이스의 주소나 SSH 접속에 사용한 주소와 다를 수 있으며, 서버에 할당된 모든 IP를 보여주지는 않습니다.

연결 방식에 따라 IPv4 또는 IPv6가 반환됩니다. 관련 옵션은 [curl 공식 문서](https://curl.se/docs/manpage.html)에서 확인할 수 있습니다. 도메인을 연결하거나 서비스를 외부에 공개할 때는 호스팅 업체가 제공한 접속 주소와 NAT 매핑, 방화벽 설정을 함께 확인하세요. IP 조회 성공만으로 웹사이트나 SSH 포트에 외부 접속이 가능하다고 판단할 수는 없습니다.

## 명령어가 실행되지 않는다면

`curl: command not found`는 curl이 설치되어 있지 않다는 뜻입니다. 사용 중인 Linux 배포판의 패키지 관리자로 설치하세요. 이름 확인 오류가 발생하면 DNS를, 연결 시간이 초과되면 서버의 외부 통신이나 프록시 설정을 점검하면 됩니다.

## 함께 활용할 수 있는 온라인 도구

[MyIP.dog 홈페이지](https://myip.dog/)에서는 현재 브라우저 연결의 공인 IP를 볼 수 있습니다. 내 컴퓨터에서 사이트를 열면 내 네트워크 주소가 표시되며, 원격 VPS의 IP가 자동으로 조회되지는 않습니다.

[온라인 도구 페이지](https://myip.dog/tools)에는 DNS 조회, IPv6 테스트, TCP 포트 확인, Ping, Traceroute, IP WHOIS, 서브넷 계산기가 있습니다. 도메인 설정은 DNS 조회로, 공개 서비스는 포트 확인으로 점검할 수 있습니다. 온라인 Ping과 Traceroute는 원격 측정 지점에서 시작하므로 결과를 읽을 때 측정 위치도 확인하세요.

VPS 공인 IP를 확인한 뒤에는 조회 시각도 함께 기록해 두세요. 설정 변경 전후를 비교하거나 지원팀에 문제를 설명할 때 도움이 됩니다.
