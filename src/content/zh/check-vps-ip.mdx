# SSH 登录 VPS 后如何查询服务器IP？一条 curl 命令就够了

*原创示意图，图中的 IP 仅用于演示。*

通过 [SSH 登录](/zh-Hans/ssh-command/) VPS 后，搭建网站、核对网络出口或排查连接问题时，经常需要查询服务器IP。查看网卡信息时，往往会遇到多个地址，难以判断公网出口。对于想快速了解当前公网出口的新手，`curl myip.dog` 是一个简洁的方法：在远程终端输入命令，就能得到这次请求使用的 IP 地址。

## 第一步：确认命令在 VPS 上执行

开始前，确认终端已经进入 VPS 的远程会话。命令应在服务器上执行；如果直接在自己的电脑上运行，查到的是本地网络的出口地址。

## 第二步：输入 curl myip.dog

现在，在远程终端执行以下命令，即可查询服务器IP：

```bash
curl myip.dog
```

成功时会返回类似下面的结果：

```text
203.0.113.42
```

上面的地址仅用于演示，实际结果以终端返回为准。`curl` 负责发起网络请求，MyIP.dog 则返回它观察到的请求来源地址。无需打开控制面板或安装查询脚本，就能核对 VPS 公网 IP。

如果希望通过加密连接查询，也可以使用 HTTPS 写法：

```bash
curl https://myip.dog
```

## 第三步：正确理解返回的 IP

需要注意，这里得到的是当前请求的公网出口 IP。如果 VPS 经过 NAT 网关、代理或 VPN，结果可能属于这些出口，与网卡地址或 SSH 登录时使用的地址不同。它也不会列出服务器绑定的全部 IP。

返回结果可能是 IPv4，也可能是 IPv6，取决于这次连接实际使用的地址类型，详见 [curl 官方文档](https://curl.se/docs/manpage.html)。因此，准备配置域名解析或开放外部访问时，应结合服务商提供的地址、入站映射和防火墙设置确认，不能只根据这次查询判断服务是否可访问。

如果提示 `curl: command not found`，说明系统尚未安装 curl，需要通过对应发行版的软件包管理器安装。如果提示域名解析失败或连接超时，可以先检查服务器的 DNS、出站网络和代理设置，再重试。

## MyIP.dog 还有哪些在线功能？

除了终端查询，[MyIP.dog 首页](https://myip.dog/)也能查看当前浏览器连接的公网 IP。它显示的是浏览器所在网络的出口；在自己电脑上打开网页，并不会自动得到远程 VPS 的地址。

[在线工具页](https://myip.dog/tools)还提供 DNS 查询、IPv6 测试、端口检测、Ping、Traceroute、IP WHOIS 和子网计算等功能。核对域名解析时可以使用 DNS 查询；检查公网服务的 TCP 端口时可以使用端口检测。在线 Ping 和 Traceroute 从远程探测节点发起，结果需要结合探测位置理解。

下次 SSH 登录 VPS 后需要查询服务器IP，先运行 `curl myip.dog`，记录返回地址与查询时间，再根据具体问题选择后续工具，就能更有条理地检查服务器网络。
