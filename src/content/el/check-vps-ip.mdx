# Πώς να βρείτε τη δημόσια IP του VPS μετά τη σύνδεση με SSH

<img src="/images/articles/check-vps-ip.webp" alt="Τερματικό SSH σε VPS με την εντολή curl myip.dog και μια ενδεικτική δημόσια IP" width="1536" height="1024" className="w-full h-auto rounded-xl border border-border" />

*Πρωτότυπη εικονογράφηση. Η διεύθυνση IP είναι μόνο παράδειγμα.*

Έχετε συνδεθεί στο VPS μέσω [SSH](/el/ssh-command/) και θέλετε να δείτε με ποια διεύθυνση βγαίνει ο διακομιστής στο διαδίκτυο; Εκτελέστε `curl myip.dog` στο απομακρυσμένο τερματικό. Είναι ένας γρήγορος έλεγχος για διάγνωση προβλημάτων δικτύου ή προετοιμασία αιτήματος υποστήριξης, χωρίς να ανοίξετε τον πίνακα του παρόχου.

## Εκτελέστε την εντολή στο VPS

Βεβαιωθείτε ότι το τερματικό βρίσκεται στη συνεδρία SSH του διακομιστή. Αν εκτελέσετε την ίδια εντολή στον υπολογιστή σας χωρίς σύνδεση στο VPS, θα δείτε τη διεύθυνση της δικής σας σύνδεσης.

```bash
curl myip.dog
```

Αν το αίτημα ολοκληρωθεί, θα λάβετε μια διεύθυνση ως απλό κείμενο:

```text
203.0.113.42
```

Η παραπάνω διεύθυνση είναι παράδειγμα. Η δημόσια IP του VPS είναι η πραγματική τιμή που επιστρέφεται στο τερματικό σας. Το curl στέλνει το αίτημα και το MyIP.dog απαντά με τη διεύθυνση προέλευσης που βλέπει. Δεν χρειάζεται πρόσθετο σενάριο αναζήτησης.

Για έλεγχο μέσω κρυπτογραφημένης σύνδεσης HTTPS, χρησιμοποιήστε:

```bash
curl https://myip.dog
```

## Τι σημαίνει το αποτέλεσμα;

Το αποτέλεσμα δείχνει τη δημόσια IP αυτού του συγκεκριμένου εξερχόμενου αιτήματος. Αν το VPS χρησιμοποιεί πύλη NAT, διακομιστή μεσολάβησης ή VPN, μπορεί να εμφανιστεί η διεύθυνση της ενδιάμεσης υπηρεσίας. Επομένως, δεν είναι απαραίτητα ίδια με τη διεύθυνση της διεπαφής δικτύου ή τη διεύθυνση σύνδεσης SSH. Η εντολή δεν εμφανίζει όλες τις IP του VPS.

Ανάλογα με τη σύνδεση, μπορεί να επιστραφεί IPv4 ή IPv6. Οι επιλογές περιγράφονται στο [εγχειρίδιο του curl](https://curl.se/docs/manpage.html). Πριν κατευθύνετε ένα domain στη δημόσια IP του VPS, επιβεβαιώστε με τον πάροχο τη διεύθυνση εισερχόμενων συνδέσεων και ελέγξτε το NAT και το τείχος προστασίας. Ένας επιτυχημένος έλεγχος IP δεν αποδεικνύει ότι ο ιστότοπος ή η θύρα SSH είναι προσβάσιμα απ’ έξω.

## Αν εμφανιστεί σφάλμα

Το `curl: command not found` σημαίνει ότι πρέπει να εγκαταστήσετε το curl με τον διαχειριστή πακέτων της διανομής Linux. Σε αποτυχία επίλυσης ονόματος, ελέγξτε το DNS. Αν λήξει ο χρόνος αναμονής, ελέγξτε την εξερχόμενη σύνδεση και τις ρυθμίσεις μεσολάβησης. Κρατήστε το ακριβές μήνυμα για τη συνέχεια της διάγνωσης.

## Περισσότερα εργαλεία στο MyIP.dog

Η [αρχική σελίδα του MyIP.dog](https://myip.dog/) δείχνει τη δημόσια IP της σύνδεσης του προγράμματος περιήγησης. Αν την ανοίξετε στον υπολογιστή σας, δεν ελέγχει αυτόματα το απομακρυσμένο VPS.

Η [σελίδα εργαλείων](https://myip.dog/tools) περιλαμβάνει αναζήτηση DNS, δοκιμή IPv6, έλεγχο θυρών TCP, Ping, Traceroute, IP WHOIS και υπολογιστή υποδικτύων. Επιλέξτε ανάλογα με το αν εξετάζετε εγγραφές domain ή μια δημόσια υπηρεσία TCP. Τα διαδικτυακά Ping και Traceroute ξεκινούν από απομακρυσμένο σημείο μέτρησης, οπότε λάβετε υπόψη την τοποθεσία του.

Σημειώστε τη δημόσια IP του VPS και την ώρα του ελέγχου. Έτσι θα συγκρίνετε ευκολότερα τα αποτελέσματα μετά από αλλαγές στις ρυθμίσεις.
