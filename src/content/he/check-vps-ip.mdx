# איך לבדוק את כתובת ה-IP הציבורית של ה-VPS דרך SSH

<img src="/images/articles/check-vps-ip.webp" alt="מסוף SSH של שרת VPS עם הפקודה curl myip.dog וכתובת IP לדוגמה" width="1536" height="1024" className="w-full h-auto rounded-xl border border-border" />

*איור מקורי. כתובת ה-IP שבתמונה היא דוגמה בלבד.*

אחרי שמתחברים לשרת VPS דרך [SSH](/he/ssh-command/), לפעמים צריך לבדוק באיזו כתובת הוא משתמש כדי לצאת לאינטרנט. מריצים `curl myip.dog` במסוף של השרת ומקבלים את כתובת המקור של הבקשה. זו בדיקה מהירה ושימושית לאיתור תקלות רשת או להכנת פנייה לתמיכה.

## מריצים את הפקודה על השרת

קודם מוודאים שהמסוף נמצא בחיבור ה-SSH ל-VPS. אם מריצים את הפקודה במחשב האישי בלי להתחבר לשרת, תתקבל הכתובת של הרשת המקומית שלכם.

```bash
curl myip.dog
```

אם הבקשה מצליחה, מתקבלת כתובת כטקסט פשוט:

```text
203.0.113.42
```

זו כתובת לדוגמה בלבד. כתובת ה-IP הציבורית של ה-VPS היא הערך שהוחזר בפועל במסוף. curl שולח את הבקשה, ו-MyIP.dog מחזיר את כתובת המקור שהוא רואה. אין צורך להתקין סקריפט נוסף לבדיקה.

לבדיקה בחיבור HTTPS מוצפן אפשר להשתמש בפקודה הבאה:

```bash
curl https://myip.dog
```

## מה התוצאה אומרת?

התוצאה היא כתובת ה-IP הציבורית של הבקשה היוצאת הזו. אם השרת משתמש בשער NAT, בשרת Proxy או ב-VPN, ייתכן שיופיע דווקא IP של אותו שירות. לכן הוא לא חייב להתאים לכתובת של ממשק הרשת או לכתובת שבה השתמשתם כדי להתחבר ב-SSH. זו גם אינה רשימה של כל הכתובות שהוקצו לשרת.

הכתובת עשויה להיות IPv4 או IPv6, בהתאם לחיבור. פרטים על האפשרויות נמצאים ב[תיעוד של curl](https://curl.se/docs/manpage.html). לפני שמפנים דומיין לשרת, כדאי לאמת אצל ספק האחסון את הכתובת לחיבורים נכנסים ולבדוק את מיפוי ה-NAT ואת חומת האש. בדיקת IP מוצלחת לא מוכיחה שהאתר או פורט ה-SSH נגישים מבחוץ.

## אם מתקבלת שגיאה

הודעת `curl: command not found` אומרת שצריך להתקין curl דרך מנהל החבילות של הפצת Linux שלכם. אם שם האתר לא נפתר לכתובת, בדקו את הגדרות ה-DNS. אם הבקשה חורגת מזמן ההמתנה, בדקו חיבורים יוצאים והגדרות Proxy. שמרו את הודעת השגיאה המדויקת להמשך הבדיקה.

## כלים נוספים ב-MyIP.dog

[דף הבית של MyIP.dog](https://myip.dog/) מציג את כתובת ה-IP הציבורית של חיבור הדפדפן. פתיחת האתר במחשב שלכם אינה בודקת אוטומטית את ה-VPS המרוחק.

ב[עמוד הכלים](https://myip.dog/tools) יש בדיקות DNS, בדיקת IPv6, בדיקת פורטי TCP, Ping, Traceroute, IP WHOIS ומחשבון רשתות משנה. בחרו כלי לפי השאלה: רשומות של דומיין או זמינות של שירות TCP, למשל. Ping ו-Traceroute המקוונים מתחילים מנקודת מדידה מרוחקת, ולכן חשוב לבדוק גם את מיקומה.

אחרי בדיקת כתובת ה-IP הציבורית של ה-VPS, רשמו גם את שעת הבדיקה. כך תוכלו להשוות אחרי שינוי הגדרות ולשתף את התמיכה במידע שימושי.
