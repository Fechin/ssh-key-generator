*यह मूल चित्र समझाने के लिए बनाया गया है। इसमें दिखाया गया IP सिर्फ एक उदाहरण है।*

आपने [SSH](/hi/ssh-command/) से VPS में लॉगिन कर लिया है और जानना चाहते हैं कि सर्वर इंटरनेट से किस IP के ज़रिए जुड़ रहा है। रिमोट टर्मिनल में `curl myip.dog` चलाएँ। नेटवर्क की समस्या जाँचने या सपोर्ट टीम को जानकारी देने के लिए यह एक आसान तरीका है; होस्टिंग का कंट्रोल पैनल खोलने की ज़रूरत नहीं पड़ती।

## कमांड VPS पर ही चलाएँ

पहले देख लें कि टर्मिनल सर्वर के SSH सेशन में है। अगर यही कमांड अपने कंप्यूटर पर बिना सर्वर से जुड़े चलाएँगे, तो अपने इंटरनेट कनेक्शन का IP मिलेगा।

```bash
curl myip.dog
```

रिक्वेस्ट सफल होने पर एक IP साधारण टेक्स्ट में दिखाई देगा:

```text
203.0.113.42
```

यह पता केवल उदाहरण है। VPS का पब्लिक IP वही होगा जो आपके टर्मिनल में वास्तव में लौटे। curl रिक्वेस्ट भेजता है और MyIP.dog उसे दिखाई देने वाला स्रोत IP वापस देता है। इसके लिए अलग से कोई स्क्रिप्ट इंस्टॉल नहीं करनी पड़ती।

एन्क्रिप्टेड HTTPS कनेक्शन से जाँच करना चाहें, तो यह कमांड इस्तेमाल करें:

```bash
curl https://myip.dog
```

## इस IP का मतलब क्या है?

नतीजे में इस खास आउटगोइंग रिक्वेस्ट का पब्लिक IP मिलता है। अगर VPS NAT गेटवे, प्रॉक्सी या VPN इस्तेमाल करता है, तो उस सेवा का IP दिख सकता है। इसलिए यह सर्वर के नेटवर्क इंटरफ़ेस या SSH से लॉगिन करने वाले पते से अलग हो सकता है। यह कमांड VPS को दिए गए सभी IP की सूची भी नहीं दिखाती।

कनेक्शन के हिसाब से IPv4 या IPv6 लौट सकता है। विकल्पों की जानकारी [curl के आधिकारिक दस्तावेज़](https://curl.se/docs/manpage.html) में है। डोमेन को VPS से जोड़ने से पहले होस्टिंग कंपनी से आने वाले कनेक्शन का पता पक्का करें और NAT मैपिंग तथा फ़ायरवॉल देखें। IP मिल जाने का मतलब यह नहीं कि वेबसाइट या SSH पोर्ट बाहर से खुल रहा है।

## कमांड में त्रुटि आए तो

`curl: command not found` आने पर अपने Linux वितरण के पैकेज मैनेजर से curl इंस्टॉल करें। नाम का IP पता निकालने में समस्या हो तो DNS जाँचें। कनेक्शन टाइम आउट हो तो सर्वर की आउटगोइंग कनेक्टिविटी और प्रॉक्सी सेटिंग देखें। आगे जाँच करने के लिए त्रुटि का पूरा संदेश संभालकर रखें।

## MyIP.dog के दूसरे ऑनलाइन टूल

[MyIP.dog का होमपेज](https://myip.dog/) ब्राउज़र के कनेक्शन का पब्लिक IP बताता है। इसे अपने कंप्यूटर पर खोलने से रिमोट VPS का पता अपने आप नहीं मिलता।

[टूल पेज](https://myip.dog/tools) पर DNS लुकअप, IPv6 टेस्ट, TCP पोर्ट जाँच, Ping, Traceroute, IP WHOIS और सबनेट कैलकुलेटर भी हैं। डोमेन रिकॉर्ड देखने के लिए DNS और सार्वजनिक TCP सेवा जाँचने के लिए पोर्ट टूल चुनें। ऑनलाइन Ping और Traceroute किसी रिमोट मापन केंद्र से शुरू होते हैं, इसलिए उसका स्थान भी ध्यान में रखें।

VPS का पब्लिक IP देखने के बाद पता और जाँच का समय नोट कर लें। सेटिंग बदलने के बाद तुलना करने या सपोर्ट से बात करने में ये काम आएँगे।
