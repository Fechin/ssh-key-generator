# Як дізнатися зовнішню IP-адресу VPS після входу через SSH

*Авторська ілюстрація. Адреса на зображенні наведена для прикладу.*

Ви зайшли на VPS через [SSH](/uk/ssh-command/) і хочете перевірити, з якої адреси сервер виходить в інтернет. Запустіть `curl myip.dog` у віддаленому терміналі. Це зручний спосіб перевірити зовнішню IP-адресу VPS під час діагностики мережі або перед зверненням до підтримки.

## Запустіть команду на сервері

Переконайтеся, що працюєте саме в SSH-сеансі VPS. Якщо виконати команду на власному комп’ютері без підключення до сервера, ви отримаєте адресу своєї мережі.

```bash
curl myip.dog
```

У разі успіху відповідь міститиме адресу звичайним текстом:

```text
203.0.113.42
```

Ця адреса наведена лише для прикладу. Зовнішня IP-адреса VPS — це фактичний результат у вашому терміналі. curl надсилає запит, а MyIP.dog повертає адресу джерела, яку бачить. Окремий скрипт для перевірки встановлювати не потрібно.

Для запиту через зашифроване з’єднання HTTPS скористайтеся таким варіантом:

```bash
curl https://myip.dog
```

## Як правильно прочитати результат

Ви бачите зовнішню IP-адресу саме цього вихідного запиту. Якщо VPS працює через NAT-шлюз, проксі або VPN, у відповіді може бути адреса цього посередника. Вона не обов’язково збігається з адресою мережевого інтерфейсу або адресою входу через SSH. Команда також не показує всі IP, призначені серверу.

Залежно від з’єднання ви отримаєте IPv4 або IPv6. Доступні параметри описано в [документації curl](https://curl.se/docs/manpage.html). Перед налаштуванням домену на зовнішню IP-адресу VPS уточніть у провайдера адресу для вхідних з’єднань і перевірте NAT та міжмережевий екран. Успішна перевірка IP не гарантує доступності сайту або порту SSH ззовні.

## Якщо виникла помилка

Повідомлення `curl: command not found` означає, що curl потрібно встановити через менеджер пакунків вашого дистрибутива Linux. Якщо не вдається визначити адресу за іменем, перевірте DNS. Якщо спливає час очікування, перевірте вихідні з’єднання та параметри проксі. Збережіть повний текст помилки для подальшої діагностики.

## Інші інструменти MyIP.dog

[Головна сторінка MyIP.dog](https://myip.dog/) показує зовнішню IP-адресу з’єднання браузера. Відкривши її на власному комп’ютері, ви не перевіряєте автоматично віддалений VPS.

[Сторінка інструментів](https://myip.dog/tools) містить DNS-запити, перевірку IPv6, перевірку TCP-портів, Ping, Traceroute, IP WHOIS і калькулятор підмереж. Для записів домену виберіть DNS, а для публічного TCP-сервісу — перевірку портів. Онлайн-Ping і Traceroute починаються з віддаленого вузла, тому враховуйте його розташування.

Запишіть зовнішню IP-адресу VPS та час перевірки. Це допоможе порівняти результати після зміни налаштувань або пояснити проблему підтримці.
