# วิธีดู IP สาธารณะของ VPS หลังเข้าสู่ระบบผ่าน SSH

<img src="/images/articles/check-vps-ip.webp" alt="เทอร์มินัล SSH บน VPS ที่รัน curl myip.dog และแสดง IP สาธารณะตัวอย่าง" width="1536" height="1024" className="w-full h-auto rounded-xl border border-border" />

*ภาพประกอบที่สร้างขึ้นสำหรับบทความนี้ IP ในภาพเป็นเพียงตัวอย่าง*

หลังเข้าสู่ VPS ผ่าน [SSH](/th/ssh-command/) คุณอาจต้องการรู้ว่าเซิร์ฟเวอร์ใช้ IP อะไรในการเชื่อมต่อออกสู่อินเทอร์เน็ต ลองรัน `curl myip.dog` ในเทอร์มินัลของ VPS ได้เลย วิธีนี้ช่วยตรวจสอบการเชื่อมต่อหรือเตรียมข้อมูลให้ฝ่ายสนับสนุน โดยไม่ต้องเปิดแผงควบคุมของผู้ให้บริการโฮสติ้ง

## รันคำสั่งบน VPS

ก่อนเริ่ม ให้ตรวจสอบว่าเทอร์มินัลอยู่ในเซสชัน SSH ของเซิร์ฟเวอร์จริง หากรันคำสั่งบนคอมพิวเตอร์ของคุณโดยยังไม่ได้เชื่อมต่อ VPS ผลลัพธ์จะเป็น IP ของเครือข่ายที่คอมพิวเตอร์ใช้อยู่

```bash
curl myip.dog
```

เมื่อส่งคำขอสำเร็จ จะได้รับที่อยู่ IP เป็นข้อความ เช่น

```text
203.0.113.42
```

ที่อยู่นี้เป็นตัวอย่างเท่านั้น IP สาธารณะของ VPS ต้องดูจากค่าที่เทอร์มินัลของคุณได้รับจริง curl จะส่งคำขอ และ MyIP.dog จะส่งกลับ IP ต้นทางที่บริการมองเห็น ไม่จำเป็นต้องติดตั้งสคริปต์ค้นหาเพิ่มเติม

หากต้องการตรวจสอบผ่านการเชื่อมต่อ HTTPS ที่เข้ารหัส ให้ใช้

```bash
curl https://myip.dog
```

## IP ที่ได้หมายถึงอะไร

ผลลัพธ์คือ IP สาธารณะที่ใช้ส่งคำขอออกไปในครั้งนี้ หาก VPS เชื่อมต่อผ่าน NAT gateway, proxy หรือ VPN ที่อยู่ที่เห็นอาจเป็นของบริการตัวกลาง จึงอาจต่างจาก IP ของอินเทอร์เฟซเครือข่ายหรือที่อยู่ที่ใช้เข้า SSH และคำสั่งนี้ไม่ได้แสดง IP ทั้งหมดที่กำหนดให้เซิร์ฟเวอร์

ผลลัพธ์อาจเป็น IPv4 หรือ IPv6 ตามการเชื่อมต่อ ดูรายละเอียดตัวเลือกได้ใน [คู่มือ curl](https://curl.se/docs/manpage.html) ก่อนชี้โดเมนมาที่ IP สาธารณะของ VPS ให้ยืนยันที่อยู่สำหรับรับการเชื่อมต่อกับผู้ให้บริการ พร้อมตรวจสอบการแมป NAT และไฟร์วอลล์ การค้นหา IP สำเร็จไม่ได้ยืนยันว่าเว็บไซต์หรือพอร์ต SSH เข้าถึงได้จากภายนอก

## ถ้าคำสั่งแสดงข้อผิดพลาด

ข้อความ `curl: command not found` หมายถึงยังไม่ได้ติดตั้ง curl ให้ติดตั้งผ่านตัวจัดการแพ็กเกจของ Linux ที่ใช้อยู่ หากแปลงชื่อโดเมนเป็น IP ไม่ได้ ให้ตรวจสอบ DNS หากการเชื่อมต่อหมดเวลา ให้ดูการเชื่อมต่อออกจากเซิร์ฟเวอร์และการตั้งค่า proxy เก็บข้อความข้อผิดพลาดไว้เพื่อช่วยหาสาเหตุ

## เครื่องมืออื่นของ MyIP.dog

[หน้าแรกของ MyIP.dog](https://myip.dog/) แสดง IP สาธารณะของการเชื่อมต่อเบราว์เซอร์ การเปิดเว็บจากคอมพิวเตอร์ของคุณไม่ได้ตรวจสอบ IP ของ VPS ระยะไกลโดยอัตโนมัติ

[หน้าเครื่องมือ](https://myip.dog/tools) มีการค้นหา DNS, ทดสอบ IPv6, ตรวจสอบพอร์ต TCP, Ping, Traceroute, IP WHOIS และเครื่องคำนวณ subnet เลือกให้ตรงกับเรื่องที่ต้องการตรวจสอบ เช่น ระเบียนโดเมนหรือบริการ TCP ที่เปิดสู่ภายนอก Ping และ Traceroute ออนไลน์เริ่มจากจุดวัดระยะไกล จึงควรดูตำแหน่งจุดวัดประกอบด้วย

เมื่อดู IP สาธารณะของ VPS แล้ว ให้จดที่อยู่และเวลาที่ตรวจสอบไว้ จะช่วยเปรียบเทียบผลหลังเปลี่ยนการตั้งค่าหรือแจ้งปัญหากับฝ่ายสนับสนุนได้ชัดเจนขึ้น
