# SSH দিয়ে লগইন করার পর VPS-এর পাবলিক IP দেখবেন যেভাবে

<img src="/images/articles/check-vps-ip.webp" alt="VPS-এর SSH টার্মিনালে curl myip.dog কমান্ড এবং একটি নমুনা পাবলিক IP" width="1536" height="1024" className="w-full h-auto rounded-xl border border-border" />

*নিজস্ব ব্যাখ্যামূলক ছবি। এখানে দেখানো IP শুধু একটি উদাহরণ।*

[SSH](/bn/ssh-command/) দিয়ে VPS-এ ঢোকার পর জানতে চাইতে পারেন, সার্ভার কোন IP ব্যবহার করে ইন্টারনেটে সংযোগ করছে। রিমোট টার্মিনালে `curl myip.dog` চালালেই সেটি দেখা যায়। নেটওয়ার্কের সমস্যা খুঁজতে বা সাপোর্টে তথ্য পাঠাতে এটি কাজে লাগে, হোস্টিংয়ের কন্ট্রোল প্যানেল খুলতে হয় না।

## কমান্ডটি VPS-এ চালান

আগে নিশ্চিত হন যে টার্মিনাল সার্ভারের SSH সেশনে আছে। সার্ভারে না ঢুকে নিজের কম্পিউটারে কমান্ড চালালে নিজের ইন্টারনেট সংযোগের IP পাবেন।

```bash
curl myip.dog
```

অনুরোধ সফল হলে সাধারণ টেক্সটে একটি ঠিকানা ফেরত আসবে:

```text
203.0.113.42
```

এই ঠিকানাটি শুধু উদাহরণ। VPS-এর পাবলিক IP হলো আপনার টার্মিনালে আসা আসল ফলাফল। curl অনুরোধ পাঠায়, আর MyIP.dog যে উৎস IP দেখতে পায় সেটি ফেরত দেয়। আলাদা কোনো স্ক্রিপ্ট ইনস্টল করার দরকার নেই।

এনক্রিপ্ট করা HTTPS সংযোগে জানতে চাইলে ব্যবহার করুন:

```bash
curl https://myip.dog
```

## ফলাফলটি আসলে কী বোঝায়?

এই পদ্ধতিতে ওই নির্দিষ্ট বাইরের দিকে পাঠানো অনুরোধের পাবলিক IP পাওয়া যায়। VPS যদি NAT গেটওয়ে, প্রক্সি বা VPN দিয়ে সংযোগ করে, তাহলে মাঝের সেবাটির ঠিকানা দেখা যেতে পারে। তাই এটি নেটওয়ার্ক ইন্টারফেসের IP বা SSH লগইনের ঠিকানা থেকে আলাদা হতে পারে। কমান্ডটি সার্ভারের সব IP-এর তালিকাও দেয় না।

সংযোগ অনুযায়ী IPv4 বা IPv6 ফেরত আসতে পারে। বিস্তারিত বিকল্পের জন্য [curl-এর অফিসিয়াল নির্দেশিকা](https://curl.se/docs/manpage.html) দেখুন। ডোমেইন VPS-এর দিকে নির্দেশ করার আগে হোস্টিং প্রতিষ্ঠান থেকে ইনকামিং সংযোগের ঠিকানা নিশ্চিত করুন এবং NAT ম্যাপিং ও ফায়ারওয়াল পরীক্ষা করুন। IP পাওয়া মানেই ওয়েবসাইট বা SSH পোর্ট বাইরে থেকে খোলা আছে, এমন নয়।

## ত্রুটি দেখালে কী করবেন

`curl: command not found` দেখালে Linux ডিস্ট্রিবিউশনের প্যাকেজ ম্যানেজার দিয়ে curl ইনস্টল করতে হবে। নাম থেকে ঠিকানা খুঁজে না পেলে DNS দেখুন। সংযোগের সময় শেষ হয়ে গেলে সার্ভারের ইন্টারনেট সংযোগ ও প্রক্সি সেটিং পরীক্ষা করুন। পরের ধাপে সমস্যা খুঁজতে পুরো ত্রুটির বার্তাটি রেখে দিন।

## MyIP.dog-এর আরও কিছু টুল

[MyIP.dog-এর হোমপেজ](https://myip.dog/) ব্রাউজারের সংযোগের পাবলিক IP দেখায়। নিজের কম্পিউটারে পেজটি খুললে দূরের VPS-এর ঠিকানা স্বয়ংক্রিয়ভাবে জানা যায় না।

[টুল পেজে](https://myip.dog/tools) DNS লুকআপ, IPv6 পরীক্ষা, TCP পোর্ট পরীক্ষা, Ping, Traceroute, IP WHOIS ও সাবনেট ক্যালকুলেটর রয়েছে। ডোমেইনের রেকর্ড দেখতে DNS এবং বাইরের TCP সেবা পরীক্ষা করতে পোর্ট টুল বেছে নিন। অনলাইন Ping ও Traceroute দূরের একটি মাপার কেন্দ্র থেকে শুরু হয়, তাই ফলাফল পড়ার সময় সেটির অবস্থানও দেখুন।

VPS-এর পাবলিক IP এবং পরীক্ষার সময় লিখে রাখুন। সেটিং বদলানোর পর তুলনা করা বা সাপোর্টে সমস্যা বোঝানো সহজ হবে।
